# TradingView setup

SHIVAY AI V10 uses official TradingView **standard alerts** and does not require a custom Pine Script for normal operation.

Follow [TRADINGVIEW_STANDARD_ALERT_SETUP.md](TRADINGVIEW_STANDARD_ALERT_SETUP.md) and copy messages from `TRADINGVIEW_ALERT_MESSAGES.json`.

The legacy Pine bridge file is retained only for backward compatibility. Do not use it for a new V10 setup.
